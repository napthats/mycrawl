# Rapid Descent 補填実験（mycrawl、実験ブランチ）

ブランチ `claude/rapid-descent-loot-experiments` での実験記録です。対象は、階数を減らした
ことで Rapid Descent に足りなくなるもの（vault の良品、shop、portal など）です。いくつかの
補填策を実装し、objstat で生成量を Descent と比べました。仕様の本体は
[rapid_descent.md](rapid_descent.md) にあります。

## 1. 計測方法

- **ビルド**: 最適化ビルドに objstat を有効にしたもの
  （`make EXTERNAL_DEFINES=-DDEBUG_STATISTICS`）。
- **固定方法**: バイナリと `dat/` を一緒にコピーして固定しました（後から dat を編集しても
  計測に混ざらないようにするため）。
- **実行**: 1 設定あたり 75 周 × 4 バッチ = 300 周（gates と経路別の計測は 150 周）を回しました。
  crawl の呼び出し方は `util/rapid-descent-loot/run_objstat.sh` と同じです（実際の計測には
  同等の作業用スクリプトを使い、C5 だけ 4 バッチを並列に実行しました）。
- **スナップショット**: 2 つあります。v2 は descent、rapid、shops、portals、gates、portal の中身に
  使いました。v3 は残りすべてに使いました。v3 での変更は、standin・targeted・minivaults の
  中身と、Lua の安全策だけです。フラグなしでは、固定シード 2 通りで objstat の出力がバイト単位で
  一致することを確かめました。対象範囲は Descent の通る 13 branch
  （D、Lair、Orc、Swamp、Shoals、Snake、Spider、Elf、Crypt、Vaults、Slime、Depths、Zot）です。
- **集計**: `util/rapid-descent-loot/analyze.py` と `mdtable.py`。通常ルートを
  D+Lair+Orc+Vaults+Slime+Depths+Zot + ¼(Lair 支流 4 本) + ½(Elf+Crypt) として 1 ゲーム
  あたりに直し、Descent に対する比で示します。±はバッチ平均のばらつきから出した標準誤差で、
  Descent 側の誤差も含みます。
- **経験値**: 生成されたモンスターの経験値に、各階の倍率 r を掛けた値です（ゲーム中と同じ扱い）。
- **portal**: objstat は portal の中身を作らないので、入口の数（Features の各入口地形）を数えました。
  中身は portal の branch だけを生成する別の計測（50 回ずつ）から、1 回あたりの量を出して掛けています。
- **補填の切り替え**: 環境変数 `RAPID_DESCENT_LOOT` で切り替えます
  （例 `RAPID_DESCENT_LOOT=shops,portals,standin:50`）。未設定なら従来とまったく同じ生成です。
  レビュー時に、固定シードで TSV がバイト単位で一致することを確認しました。

- **shop の外**（床と vault）の良品は、すでにほぼ Descent 並みです。
- **不足の大部分は次の 3 つです。**
  1. 飛ばした階にあった **shop**（serial_shops の確率ロール）。
  2. 飛ばした階にあった **portal 入口**。
  3. 飛ばした階の vault にあった **アーティファクト**。
- **技能書の不足もほぼ shop 由来です**（shop 内の技能書 0.54、shop 外 0.97）。
- **portal の中身**（推定、1 ゲームあたり）: アーティファクト 7.9 → 4.5 個、装身具 5.0 → 2.7 個、
  巻物 10.8 → 5.9 枚。
- **ルート 1 本だけを生成した計測**（Swamp+Elf 経由と Snake+Crypt 経由）でも、portal 入口は
  0.54 と 0.53、アーティファクトは 0.86 でした。1 周で Lair 支流を 4 本とも作ることによる
  偏り（uniq 系 portal の取り合い）は小さいと判断しました。

## 3. 試した補填

いずれも「飛ばした階の分」に比例させています。飛ばした階は、その上の最も近い残存階が
受け持ちます（branch の最初の残存階は、それより上の階も受け持ちます。たとえば Orc:2 は
Orc:1、Swamp:2 は Swamp:1 と 3 を受け持ちます）。

| フラグ | 内容 | 実装 |
|---|---|---|
| `shops` | serial_shops（shop を置く CHANCE vault）の確率を「1 + 受け持つ階数」倍にする（上限 100%） | maps.cc `_vault_chance_roll` |
| `bigshops` | shop の品数を「1 + 受け持つ階数」倍にする（上限 26） | dungeon.cc `place_spec_shop` |
| `portals` | 受け持つ階ごとに、その階の深さで portal 入口の CHANCE を振り直し、当たったものをこの階に置く。Vaults の部屋で出る Wizlab・Desolation・Necropolis も同様 | dungeon.cc `_place_chance_vaults`、maps.cc `random_chance_maps_for_stand_in`、dlua `v_rooms.lua` |
| `gates` | Abyss・Pan の門について同上。実際には、Descent が Depths:3 に必ず置く Abyss の門を Depths:2 で補うだけになります（Depths:2 には Pan の門が必ずあるため） | 同上 |
| `standin[:G]` | 「受け持つ階の数 × G%（既定 100%）」個（端数は確率で丸める）の良品を床に置く。作り方は vault の `\|` と同じ（ISPEC_GOOD_ITEM、武器・防具・装身具・本・杖・雑貨に偏った表） | dungeon.cc `_builder_items` |
| `targeted[:G]` | 同上。ただし不足を狙った表（装身具 40、武器 25、防具 15、杖 10、技能書 10）を使う | 同上 |
| `minivaults` | 受け持つ階ごとに minivault の抽選を追加で行う。候補はその階の深さで選ぶが、重みは今の階の深さで決まり、レイアウトとの相性の確認は省かれる | dungeon.cc `_place_minivaults` |
| `bonus:N` | 床アイテムの上乗せ率（既定 125%）を N% に変える | rapid-descent.cc |

- **`shops`**: 不足の大きかった shop の数と品数が 0.89 まで戻りました。

  戻ります。ダンジョン内のアイテムは変わりません。portal を回る時間は増えます。
- **`standin`**（G=100%）: アーティファクトが 0.98 になります。
  - 杖 1.10、shop の外の装身具 1.14、雑貨 0.99 です。
  - 技能書は 0.79 にとどまります（`|` の表では技能書がまれなため）。
- **`targeted`**（G=100%）: アーティファクトは 0.98 です。
  - 装身具 1.09、技能書 1.13、杖 1.07 です。
  - shop の外の技能書が 1.80 で、床に落ちている技能書が多すぎます。
- **`minivaults`**: アーティファクト 0.92、魔法書 1.00 と効果は小さいです。
  - 追加 vault のモンスターにも倍率 r がかかるため、経験値が 1.03 に増えます。
  - minivault は 1 つあたりの戦利品が少なく、Vaults では minivault がもともと置かれません。

## 6. 推奨

**C5（`shops,portals,standin:50,bonus:115`）** がもっとも Descent に近くなりました。

| 項目 | C5 の比 |
|---|---|
| モンスター経験値（×r） | 1.00 |
| 巻物・薬・ワンド | 1.00〜1.03 |
| 金 | 0.93 |
| 装身具 | 0.99 |
| 杖 | 1.01 |
| 雑貨 | 0.99 |
| 羊皮紙 | 1.00 |
| タリスマン | 1.02 |
| shop の数・品数 | 0.90 |
| portal 入口 | 1.01 |
| アーティファクト（portal の中身込み） | 0.96 |
| 技能書 | 0.91 |
| 魔法書 | 0.85 |

各要素の役割:

- **`shops`**: shop の数と品数を戻します（技能書・装身具・羊皮紙の不足の大部分）。
- **`portals`**: portal 入口と、portal 内の戦利品を戻します。
- **`standin:50`**: 飛ばした階 2 つにつき 1 個の良品を置き、vault 由来のアーティファクト・杖・
  雑貨を戻します。
- **`bonus:115`**: shop と良品で増えた分だけ、床アイテムの上乗せを 125% から 115% に下げ、
  消耗品の過多を相殺します。

別案:

- **良品を多めにしたい場合は C2**（上乗せ 125% のまま）です。アーティファクトは 0.99 ですが、
  消耗品が 1.08〜1.10 と少し多くなります。
- **`targeted`** は技能書を確実に戻せます。ただし、床に落ちている技能書が多すぎる
  （shop 外 1.37〜1.80）ので、使うなら確率を下げる必要があります。
- **`bigshops`** は数字の上ではよく戻ります。ただし shop の種類や Bazaar が戻らず、
  1 つの shop が大きくなるだけなので、`shops` を優先しました。
- **`minivaults`** は効果が小さく、経験値が 3% 増えるので、推奨には含めません。
- **`gates`** は Abyss の門の数（0.77 → 1.47 個/ゲーム）だけを戻します。Abyss に行く
  機会を Descent 並みにしたい場合に足してください。

時間への影響: `shops` と `portals` は、飛ばした階にあったはずの shop や portal を残した階に
置き直すものです。そのため、プレイ時間は補填なしの Rapid Descent より少し増えます。
portal は 1 ゲームあたり約 1.5 個増えます（portal 1 つで数分〜10 分程度）。

## 7. 計測の限界

- **objstat は生成量だけを数えます。** プレイヤーが全部を見つけ、拾い、買うことを前提にした
  量です。shop の品は金で買う必要があります（C5 の金は 0.93）。
- **portal の中身は概算です。** portal の branch を単独で 50 回ずつ生成して得た値に、
  入口の数を掛けています。単独生成では入口側の状態を引き継がないので、Necropolis が浅い深さで
  作られる、Bailey や Ice Cave の種類が固定されない、といったずれがあります。
- **モンスターの持ち物（武器・防具・矢弾）は補填の対象外です。** 持ち物は倒すモンスターの数に
  比例して 0.60〜0.66 になり、床や vault の分を含めた総数では 0.71〜0.78 です。大半は
  ゴミ装備です。
- **objstat の TSV は小数 2 桁で丸められます。** そのため、まれな品の階ごとの値には小さな
  誤差があります。
- **1 周で 13 branch を全部作る objstat は、uniq な portal を経路外の branch でも消費します。**
  経路 1 本だけを作る計測で確認したところ、入口の比は同じでした。補填なし: Swamp+Elf 経由 0.54、
  Snake+Crypt 経由 0.53。`portals`: それぞれ 0.95 と 0.95。
- **Vaults の部屋で出る portal（Wizlab・Desolation・Necropolis）は、1 回の部屋選びで当たりが
  1 つまでです。** そのため、複数当たったときの 2 つ目以降は失われます（影響は小さいです）。
- **実プレイでの時間や難易度は計測していません。**

## 8. 再現方法

```sh
cd crawl-ref/source
make -j4 EXTERNAL_DEFINES=-DDEBUG_STATISTICS
D=/path/to/snapshot; mkdir -p $D && cp crawl $D/ && cp -r dat $D/ && ln -s $PWD/settings $D/
$D/crawl -dir $D/db -builddb
U=util/rapid-descent-loot
$U/run_objstat.sh $D res/descent -descent 75 4
$U/run_objstat.sh $D res/rapid -rapid-descent 75 4
RAPID_DESCENT_LOOT=shops,portals,standin:50,bonus:115 \
    $U/run_objstat.sh $D res/c5 -rapid-descent 75 4
# portal の中身
$U/run_objstat.sh $D res/portal-loot -descent 25 2 \
    Sewer,Ossuary,Bailey,IceCv,Volcano,WizLab,Desolation,Gauntlet,Bazaar,Necropolis
python3 -I $U/mdtable.py res descent rapid c5
python3 -I $U/portal_loot.py res portal-loot descent rapid c5
```
